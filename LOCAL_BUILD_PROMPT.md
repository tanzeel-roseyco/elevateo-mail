## Complete the backend, not just the screen

Use a real local Supabase/PostgreSQL/Auth/Storage environment, migrations and scoped access checks. Seed synthetic users and mailboxes, including a second organization and a restricted mailbox for negative tests. Use locally generated disposable development secrets stored in ignored files; these are not production credentials. Use the real authentication and authorization path in local mode, never an unconditional logged-in user or universal service-role bypass.

Implement the accepted Rails API and worker sharing domain code with the documented draft versions, immutable approved send snapshots, job leases, audit records, signed-event ingestion, message routing, private attachments and revocable connector grants. The first complete journey is login → receive synthetic mail → assign → draft → resolve a concurrent edit → approve → queue → simulate provider acceptance → show result → receive a reply. Data must survive service restarts.

Make the local mail provider deterministic and persistent enough to test duplicate requests, timeouts after acceptance, delayed/reordered/duplicate webhooks, expired retry windows and worker crashes. Keep its acceptance ledger outside the application's restore target so rollback cannot erase external-send evidence. Route simulated inbound events through the same verification and durable ingestion code as live events, with a development signing secret. A local-mode indicator must make simulated sending unmistakable. Test attachments through real local private storage and processing, with new downloads checked through an authenticated API/proxy; keep Storage signed URLs server-side so revoked access cannot reuse them.

Implement the real Resend adapter behind the same interface and validate requests/responses with offline transport fixtures. Local mode must not contact Resend, live SMTP, production data or external AI services. Dependency downloads needed for builds are separate from runtime mail egress. Live mode must fail closed when required configuration is absent; never silently select live transport or fall back from failed live operations to simulated success. The nine-address inventory may include aliases. Keep Instantly warmup disabled: it sends real mail and requires an explicit change to the no-live-send instruction. Existing Resend CLI discovery/read-only checks and account connection belong to the staged activation plan, with side effects checked before any account wizard completes.
