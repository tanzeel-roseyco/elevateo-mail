# Elevateo Mail web UX audit and redesign — 2026-10-18

Scope: `apps/web` (React 19, Vite, Tailwind 4). Branch `design/opus-ui-refresh`. Evidence is the demo build
(`npx vite --mode demo`, synthetic fixtures) captured with Playwright 1.64 in Docker on fleet-02 by
`apps/web/.design-capture.mjs`: 17 routes plus the sign-in screen and the mobile navigation drawer, at
desktop 1440x900 and mobile 390x844, in light and dark (74 images per set).

- Before: `docs/design/screenshots-20261018/before/before-<route>-<desktop|mobile>-<light|dark>.png`
- After: `docs/design/screenshots-20261018/after/after-<route>-<desktop|mobile>-<light|dark>.png`

Routes captured: home, inbox, inbox-unread, thread, drafts, draft-editor, send-review, members, search,
campaigns, campaign-new, leads, accounts, analytics, people, settings-personal, settings-org, signin, nav-drawer.

## 1. Information architecture before

```
Sidebar
  PERSONAL            <- one bucket for everything that is not outreach
    Search
    <each mailbox>    (Drafts, Members appear only while the mailbox is open)
    People
    Personal settings
    Organization settings
  OUTREACH
    Campaigns, Leads, Accounts, Analytics
Header: org · user, search + scope select + Go, "Simulated local mail", account
Home (/): "Select a mailbox" placeholder
```

No route showed which area it belonged to or what it was for; nested screens relied on page-specific back links.

## 3. Redesigned IA and navigation

```
Today                         /                       what needs attention
Mail
  Search                      /search
  <each mailbox>              /mailboxes/:id          inbox
    Drafts                    /mailboxes/:id/drafts
    Members                   /mailboxes/:id/members  (when allowed)
Outreach
  Campaigns, Leads, Accounts, Analytics   /outreach/*
Contacts
  People                      /people
Settings
  Personal                    /settings/personal
  Organization                /settings/organization
```

- Every routed screen gets a context strip above its content: breadcrumb (group / place, including the
  mailbox name), one-line purpose, and a back link on nested Outreach screens. Mail detail screens
  (thread, draft, send review, send status) already had their own back link, so the strip adds none
  there. The table lives in `apps/web/src/app/pageMeta.ts` (pure, unit tested); pages keep their own `<h1>`.
- The home screen is now **Today**: unread replies and open drafts across all mailboxes (real gateway
  reads, first page per mailbox, "N+" when more exist), the daily send limit (30 per mailbox x mailboxes),
  and an honest "not reported by the server yet" tile for approvals and failures, plus a mailbox list with
  per-mailbox unread and draft counts. Quota usage, approvals and failures are not in the current API
  contracts, so no numbers are invented; the tiles say so.
- Sections are registered by job in `featureRegistry.ts` (`mail | outreach | contacts | settings`); there is
  still no mode switch and the URL alone selects the current item.

## 4. Visual system

Tokens in `apps/web/src/styles/index.css`:

- Colour: cool neutral greys, never cream. Light: canvas `#eceef2`, panel `#ffffff`, subtle `#f4f5f8`, line
  `#dde0e6`, text `#14161a`, muted `#555b66`. Dark: canvas `#141619`, panel `#1c1f23`, subtle `#262a2f`,
  line `#33373e`. Gold `#c9a227` stays the single accent (`--accent-text` `#7a6218` light / `#e3c35c` dark).
- Elevation: `--elev-1` resting panels, `--elev-2` hover/popover; exposed as `shadow-1` / `shadow-2`.
- Radius: Tailwind scale on purpose — `rounded-md` 6px controls, `rounded-lg` 8px rows, `rounded-xl` 12px panels.
- Type: system sans; `.page-title` 20/650 for every page title, 15px section headings, 13px body-secondary,
  12px labels. Group labels are sentence case (no tracked caps, no monospace eyebrows).
- Components: `.panel` surface recipe, icon set extended (Home, Inbox, Draft, Users, Send, At, Chart,
  Settings, Building, Chevron), EmptyState with a neutral icon tile.
- Avoided on purpose: cream backgrounds, italic accent words, numbered 01/02/03 labels, monospace eyebrows,
  pill buttons, purple/blue gradients, glassmorphism, custom cursors.

## 5. States, keyboard and screen readers

- Outreach loading / unavailable / empty / error states render as panels; the paused-outreach notice is a
  warn callout. Text and roles are unchanged so existing tests and screen-reader output stay identical.
- Nested `<main>` in draft editor, send review and send status error states replaced with `<div>`.
- `#main` and headings that take programmatic focus (`tabindex="-1"`) no longer draw a focus ring; every
  interactive control keeps the 2px `--accent-text` ring.
- Breadcrumb is `nav[aria-label=Breadcrumb]` without `aria-current`, so the rail keeps the only current link
  per landmark (asserted by `collaborationNav.test.tsx`).

## 6. Design references

Reviewed in `~/em-work/design-refs` (fleet-02): design-taste `c4a6bff` (MIT) — its "never list" and
"read the room" pre-flight were applied as the guide; better-design `e146625` (MIT) — its skill needs a
Better Design MCP that is not connected here, so none of its guidance is claimed; superdesign `49e2b9d`,
canvas-ui `a04a99b` (MIT + Commons Clause), paper-design/shaders `43cd68d` (Apache-2.0), uilayouts
`88d827d`, motion-primitives `120f64f`, cursify `b3a173c`. No code or dependency was adopted: this is an
all-day work tool, the requested shader would only fit the sign-in screen, and a WebGL dependency there
would cost bundle size and a reduced-motion path for no task benefit. Cursor effects were rejected outright.

## 7. Not done (and why)

- Quota usage, approvals and failures on Today: not served by the current API; adding them needs a backend
  contract change, which was out of scope (`apps/server` and contracts unchanged).
- Inner layouts of individual feature pages (thread reader, draft editor, members, organization settings) were
  only restyled through shared tokens; their structure is owned by feature modules and was left intact.
- Sign-in screen keeps its existing layout; no shader was added (see section 6).
