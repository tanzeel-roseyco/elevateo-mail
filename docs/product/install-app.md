# Install Elevateo Mail

Elevateo Mail can open in its own app window. Installation uses your browser and the same website account. It does not enable offline mail or background sending.

## Chrome and Edge on a computer

Open Elevateo Mail over HTTPS. Choose Install app when the page button becomes available, or use the install option in the browser address bar or menu. Confirm the browser dialog. Launch the app from your applications list.

Choosing Not now hides the page invitation on later visits in that browser. Install help remains available. You can still install through the browser menu.

## Android

Open the site in Chrome. Choose Install app in the page or the browser menu and confirm. Some browsers call this Add to home screen. Open the new icon to launch the app.

## iPhone and iPad

Open the site in Safari. Open Share, choose Add to Home Screen, then Add. Enable Open as Web App if your version shows that option. There is no automatic installation dialog on iOS. Launch the icon from the home screen.

## Safari on Mac and other browsers

In Safari versions that support web apps, use File, then Add to Dock. Other browsers may offer an installation or home-screen shortcut option. If they do not, use the website normally.

## What works offline

After one successful online visit, the app can reopen its interface without a connection. Your browser can remove this saved interface when storage is low or site data is cleared.

Mail, search results, attachments and account data are not saved by the offline worker. Opening the app offline cannot restore your mailbox. Draft edits already open in a window stay in that window's memory. Keep the window open until you can save online; closing it can lose unsaved edits.

Writes need a working connection. Saves and send approvals are not queued or replayed when the connection returns. If an approval result is uncertain, check its status before taking another action. A failed connection is not proof that the server did nothing. Existing draft version conflicts still need to be resolved.

## Updates

When a new version is ready, a notice asks you to save drafts and resolve pending approvals. Close every Elevateo Mail tab and app window, then reopen. The app never forces a reload to apply an update. An old background window can keep the update waiting. Old app-shell caches are removed when the new version activates.

## Appearance

The app uses a white and gold appearance and supports phone safe areas. The launch background and browser theme colour are white. Browsers control the launch screen and may keep old icon or launch metadata until the app is reinstalled.

## Shared computers

Sign out before handing over the computer. Sign-out hides protected content in other open app windows and clears Elevateo's local settings and approval recovery records. Only static interface files and the nonpersonal install-dismissal preference remain. If sign-out or local cleanup fails, follow the displayed instructions; close every app window and clear this site's browser data before sharing the device. Do not treat closing the window as signing out.

## Troubleshooting by symptom

### No install option appears

If the Install app button is unavailable, use Install help below it. Check that you are using HTTPS and a browser that supports installation. The app may already be installed. Use the browser menu, or Safari's Share menu on iOS. Private browsing and device policies can prevent installation.

### The app will not reopen offline

Open it online once and let it finish loading. Storage may have been cleared or offline setup may have failed. Offline setup requires all static files to be available and unchanged during installation. Authentication pages and API routes never have an offline fallback.

### An update stays waiting

Save your work, resolve pending approvals, and close all tabs and app windows for this site. Then reopen it. Do not close an unsaved draft simply to hurry an update.

### Mail or a save fails on a poor connection

Reconnect and use the existing retry or reload control. Check uncertain approval status instead of approving again. The app does not automatically retry writes. A browser's online indicator does not guarantee the server is reachable.

### Sign-out reports a cleanup problem

Close all Elevateo Mail windows and clear this site's cookies and storage in browser settings before sharing the computer. This removes the offline shell too. If server sign-out failed, retry it once connected.
