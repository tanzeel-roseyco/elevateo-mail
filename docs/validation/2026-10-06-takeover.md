## Implemented scope and limits

Private API UI covers inbox/plaintext reading, explicit contact consent, suppression, immutable send review, uncertain-response recovery, campaign drafts/schedules, saved short sequences, permissions and operational counts. Each send requires approval. Sequence activation defaults off; a guarded Resend-only pilot switch checks the current receiving-channel configuration and permissions at approval and dispatch. Channel rotation or removal blocks stale approvals, and each next step requires the previous step to be accepted. These fixture tests do not establish live-provider acceptance. Gmail sequences remain unavailable.

Resend encrypted credentials, verified sender admission, credential-bound dispatch, signed events and unsubscribe tokens are configuration-gated. Unknown outcomes retain reservations and are never blindly resent. Signed inbound reply correlation can stop campaigns without treating sender claims as authenticated identity. It requires an operator-approved receiving subdomain; root MX is untouched. Already in-flight mail cannot be recalled.

Google login, Gmail sync/manual sending and sender-only threaded replies are configuration-gated. Replies preserve stored source/subject metadata; incomplete, imported and custom-Reply-To sources cannot thread. Gmail is manual-only; campaign reply-stop is supported through Resend receiving. Cloud sync starts at most two mailbox pages per minute: 100 continuously busy mailboxes take about 50 minutes per round. Notifications require an open, refreshing tab; background push is absent.

JSON import is bounded to 25 messages/128 KiB and never infers consent. Search examines at most 1,000 metadata rows. Optional Hunter enrichment stores encrypted user keys and requires an explicit credit-bearing lookup; it does not personalize or change consent. DNS support is a read-only, approved-subdomain planning boundary, not a DNS-writing executor or management UI. Job health, retention and a restore runbook are implemented; an independent off-site recovery rehearsal remains outstanding.

AI selected-context/draft routes and a 60-second single-use session-bound native ticket are implemented. A completion lease binds draft output to the request. Windows process containment limits time/output and kills descendants; it is not a filesystem/network sandbox. The connected desktop GUI handoff passed its Docker compile and four native tests; frontend tests are included in the final web suite. Target-OS packaging scripts and a manual artifact workflow are provided, but no installer was built. Live Claude execution, a supported Codex adapter, macOS execution, packaging/signing and installed-app acceptance remain outstanding.
