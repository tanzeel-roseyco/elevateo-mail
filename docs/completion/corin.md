It parses a single plain-text leaf with optional bounded plain/octet attachments, drops all attachment bytes from its DTO, sanitizes displayed headers and filenames, rejects HTML and oversized or malformed input, and calls an injected atomic `insert_once` store. Duplicate identity is `(organization_id, mailbox_id, provider, provider_event_id)`. The caller must establish mailbox authorization from a trusted session; caller-supplied grants are not suitable for an HTTP route. No provider token, network call or live mail is present.

Its checked SQL function records receipt, thread and message in the caller's protected write transaction; a conflict returns the original IDs only if the content digest matches. Deferred foreign keys make an incomplete receipt uncommittable. The API role receives function EXECUTE only and no table DML. The guarded V2 controller candidate uses session/CSRF protection, checks the authenticated actor, validates mailbox visibility via RLS and is disabled except for explicitly enabled test environment. Cassian reserved `POST /v2/test/inbound/fake` and owns route/contract registration. Attachment metadata is persisted in the private receipt; bytes, quarantine/storage and authorized download are not implemented. This slice is not a pilot or production inbound capability. Unsupported providers return `unsupported_provider` from the capability query.
