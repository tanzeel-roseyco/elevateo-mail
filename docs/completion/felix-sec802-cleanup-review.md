## Confirmed defect

**MEDIUM — a failed rollback can mask the original fixture-cleanup error** (`organization_access_fixture_cleanup.rb:64–66`). The method rescues a DELETE/trigger/COMMIT failure and immediately calls `@admin.exec("ROLLBACK")`; if that call itself raises after connection loss, its new `PG::Error` replaces the original cause. The new test at lines 44–50 injects failure in `prepare_organization_fixture_cleanup`, outside this rescue, so it does not catch this double-fault path. Capture the first exception, attempt rollback only on a live connection, suppress/log a secondary rollback error while preserving the first, and add a double-fault fixture. Sabine, Cassian and root were notified immediately. **Density:** 1 confirmed defect / 314 unique reviewed LOC = **3.18 defects/KLOC** static; runtime defect density is unmeasured.
