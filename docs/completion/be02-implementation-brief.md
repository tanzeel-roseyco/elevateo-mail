## Exact A wire contract

Keep the four existing GET schemas unchanged. `Session` below is existing `#/components/schemas/Session`; `Id` is UUID; `Token` is `[A-Za-z0-9_-]{16,256}`; `Timestamp` is RFC3339 UTC. All object fields are required except marked optional; reject additional properties, duplicate JSON keys and duplicate/unknown query parameters before framework merging.
`Lifecycle={session:Session,access_expires_at:Timestamp}` (20 KiB max); `Challenge={csrf_token:Token,expires_at:Timestamp}` (1 KiB max). Errors retain `{code,message,request_id}`, message <=256 characters, request_id 1..128, total <=4 KiB. Codes/statuses: 400 request_invalid/cursor_invalid, 401 unauthenticated, 404 not_available, 409 context_changed, 429 rate_limited, 503 temporarily_unavailable. No upstream body or account existence leakage.
All JSON responses: application/json, Cache-Control:no-store, Vary:Cookie, X-Content-Type-Options:nosniff. All POSTs require exact configured Origin and X-CSRF-Token; entry/refresh use challenge proof, ordinary mutations use session proof plus canonical context/version headers. No permissive CORS/API redirects/browser bearer storage. Auth JSON input <=8 KiB; email 1..320 characters and email validation; password <=1024 UTF-8 bytes, nonempty for login, minimum 12 characters for accept matching configured policy.

## Session and transaction invariants

D02-D05 govern: online /user plus restricted bound-Auth-session predicate, verified issuer/audience/algorithm/exp/sub/non-nil sid, no positive cache/offline grant. Predicate owner may SELECT only auth.sessions(id,user_id,created_at,not_after); API/worker cannot directly read Auth/private sessions. Owners NOLOGIN/non-superuser/NOBYPASSRLS, fixed search_path/qualified SQL, no PUBLIC execute. Organization discovery has a narrow verified-user policy.
Local absolute session <=12 hours from Auth creation, idle <=30 minutes; Auth timebox 12 hours/JWT 3600 seconds. Verify effective Auth inactivity/low-AAL/single-user policies disabled; mismatch fails acceptance, not independent preparation. Expired JWT cannot read but may refresh; expired local session cannot refresh/global-logout.
Total deadline 10 seconds; HTTP connect 500 ms/total 2 seconds, SQL statement 3 seconds/lock 1 second, clipped to remaining deadline. No transaction across HTTP. Refresh durably claims before one call and publishes by claim/generation compare-and-swap; no late publish after logout/deadline. Dead/ambiguous claim requires reauthentication, no lease-stealing retry. Local-first logout records durable upstream intent for bounded existing-worker reconciliation. Pending entry records staged/verifying/password_pending/completed/uncertain states; never blindly replay ambiguous one-time verify.
Reads use one REPEATABLE READ READ ONLY snapshot S for local authority/data after Auth validation. Before-S revocation denies; after-S one whole old response may finish within deadline. Same-snapshot reread cannot detect concurrent commit; Auth HTTP and S are not atomic. Idle maintenance is separate. Writes lock local session, sorted generation guards, business rows, recheck authority; guarded membership writes atomically bump generations and preserve removal/re-add tombstones. No direct API membership writes.
401 precedes stale-context 409; valid foreign/hidden objects 404. Signed expiring cursors bind actor/org/context/generation/resource/filter/order/limit. Frontend rejects superseded successes/errors, clears current invalidation, retries bootstrap once on 409 and preserves unsaved text on 503; timeout does not prove save.
