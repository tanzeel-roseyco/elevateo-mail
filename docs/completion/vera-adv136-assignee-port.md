The gateway validates mailbox UUID, integer limit 1–50, cursor length 1–2048 and URL-encodes its query/path. It forwards cancellation and both session proof headers to the shared GET transport. Strict response parsing bounds the page to 50 UUID-only items, rejects extra profile fields, and permits an empty page/null continuation. Before return it checks exact context, authorization version and mailbox equality. The body cap is 16,384 bytes. No writes, roster-derived identities or enrollment are introduced. Design tradeoff: the narrow UUID-only port prevents accidental use of roster profile/enrollment data and keeps eligibility authority at the server. Shared bounded transport and schema parsing avoid duplicate protocol logic. Response scope equality protects against foreign responses but cannot replace current-session invalidation or final write authorization; those remain integration seams. A generalized roster abstraction would weaken the deliberate distinction without helping this read operation.
