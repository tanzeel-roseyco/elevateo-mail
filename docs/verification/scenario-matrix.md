The production entry imports `createHttpGateway()` only, with no fixture fallback; the gateway uses root-relative `/v1/*` and same-origin credentials. Exact pathname `/auth/complete` (optional trailing slash) selects `AuthCompletePage`; other navigation uses `App`'s `HashRouter`. The full Vite config has no API proxy or API-origin configuration. Existing Playwright launches `npm run dev:fixtures`, so its results belong to the mock lane.

Internal HTTP real integration cannot establish TLS production-cookie security; fixture, internal HTTP, TLS and unrun evidence remain separate. Auth entry is staged server-side, followed by a fixed query-free callback and explicit POST acceptance without an Auth token in the browser.
