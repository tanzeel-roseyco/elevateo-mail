## Analytical simulations and tradeoffs

These are enumerated interleavings and arithmetic, not software execution, timing measurements, Docker results or an Obsidian simulation. Theoretical tools are linearizability, happens-before ordering, monotonic knowledge, an external side-effect model and fail-closed authorization. Practical tradeoffs are short transactions, bounded retries, limited privileges and operational recovery.

| Scenario and trace | Selected result | Alternative / cost |
| --- | --- | --- |
| A and B approve v4 under different keys. A obtains draft lock, inserts all four artifacts, consumes and commits; B then reads consumed v4 with matching digest. | B adds only its operation binding and returns the same send ID. Cardinalities: intents=1, jobs=1, approval audits=1. | Unique(version) alone allows later versions if someone reopens draft. Unique(draft) rejects that path. |
| Save S and approval A contend on `draft-id:X`. S first -> v5; A first -> consumed v4. | Either S succeeds and A conflicts, or A succeeds and new S gets draft_consumed. Earlier successful save replay still succeeds. | No optimistic read-then-insert outside the shared lock. |
| Revoker R locks session/generation before final worker W; alternate ordering W then R. | R first: W fails current checks, zero I/O. W first: authorization commit precedes R; already authorized effect may occur. | Unlocked membership read admits R commit between check and authorization, violating the stated boundary. |
| Cancel C locks job before boundary W; alternate W then C. | C first: cancelled, no attempt. W first: first_possible_at set, C latches stop_requested; unknown must reconcile. | Prevents the false assurance of cancelled after a timeout. |
| Lease generation 7 expires after authorization; generation 8 claims reconciliation; worker 7 returns acceptance. | Worker 7 appends matching-attempt evidence but changes zero job rows. Worker 8 validates and promotes accepted. | Dropping stale evidence loses useful knowledge; permitting stale projection destroys fencing. |
| Normal profile: uncertain first call, no provider policy. | Exactly one driver invocation; unknown -> needs_review if no evidence. No key rotation. | Reduced availability deliberately avoids unsupported delivery guarantees. |
| Synthetic test only: W=600 s, bounded allowance A=90 s, first_possible_at=t0. | Persist deadline t0+510 s; attempt admission requires current time plus remaining bounded call budget strictly before deadline. At or after deadline: no submission. | These numbers are fixture arithmetic, not production settings or a Resend guarantee. |
| Worker passes last local check, is suspended, then resumes outside any window. | Database fence blocks result writes; it cannot stop a socket send. BE03 has no network implementation; BE04 retries stay disabled without a bounded lifetime/egress mechanism. | A local clock check reduces risk but cannot establish exactly-once delivery. |
| Backup has queued X/no first timestamp; lost timeline accepts X; backup restored after provider retention. | External incarnation changes; X remains needs_review with no submission even after global release. BE03 cannot project external acceptance without its lost attempt; BE04 owns that authenticated evidence path. A surviving attempt still permits late-evidence projection while held. | A timestamp reset or ledger absence would otherwise manufacture a new attempt window; calling the restored null timestamp safely cancellable would hide uncertainty. |
| Raw generation changes for an unrelated mailbox, or approving session expires before dispatch. | Conservative hold/review; no silent re-approval under a worker identity. | This may block more jobs than strictly necessary. Avoid granular capability-generation infrastructure until product evidence justifies it. |

For n ready jobs and k workers, SKIP LOCKED allows distinct row claims while preserving per-job ownership; no throughput figure is claimed. The organization policy guard serializes short approval/authorization checks within one organization. This is acceptable for the initial nine-address scope, avoids suppression phantom races and is simpler than locking per-recipient gaps; measure contention before introducing finer locks.
